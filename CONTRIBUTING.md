# Contributing

Contributions and feedback are welcome. This project is young, still being
tested, and benefits from real-world use reports, bug reports, filter
improvements, and code changes.

## Questions and feedback

Please use the **issue tracker** for:

- Questions about how the tools work
- Feedback on filters, false positives, or API behaviour
- Feature requests
- Bug reports

Open an issue before starting large changes so we can align on approach.

## Pull requests

PRs are appreciated. Keep changes focused and easy to review.

In the **PR description**, state clearly:

1. **What use case is addressed here?**  
   Who benefits, and in what situation?

2. **What real world problem is being solved?**  
   What concrete pain or gap does this fix or improve?

PRs that skip those two points may be asked to revise the description before
review continues.

### Checklist

- [ ] PR description answers both questions above
- [ ] Related issue linked (if one exists)
- [ ] Both Python and bash tools updated when behaviour is shared
- [ ] Examples or docs updated when user-facing behaviour changes
- [ ] No credentials, tokens, or secrets in the change
